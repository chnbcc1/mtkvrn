# Yerel geliştirme — aşama 1

Ana dal değiştirilmez. Bu dal mevcut oyunu yerel Vite sunucusunda açar. Phaser geçişi ve sahne düzenleme henüz yapılmamıştır.

1. Node.js LTS kurun (https://nodejs.org/).
2. GitHub Desktop ile chnbcc1/mtkvrn deposunu klonlayın ve phaser-test dalına geçin.
3. GELISTIRME-BASLAT.bat dosyasını çalıştırın. İlk çalıştırmada ücretsiz npm bağımlılıkları kurulur.
4. Tarayıcıda http://localhost:5173/gelistirme.html açılır. Dosya değişikliklerini Vite izler.
5. Telefon için güvenilir aynı Wi-Fi ağı üzerinde terminaldeki Network adresini kullanın. Windows güvenlik duvarında yalnızca özel ağ erişimine izin verin. İş bitince Ctrl+C ile sunucuyu durdurun.

Kurallar: deneme-v36/docs/PROJE_ANAYASASI.md önce okunur. Soru bankası ve onaylı karakterler korunur. Yayına otomatik gönderim yoktur. Telefon ölçülerinde iframe ön izlemesi gerçek iOS/Android testi yerine geçmez.

Sonraki aşama: mevcut orman sahnesi ve F03 yerleşim kodunun analizi, otomatik testler, gerçek veri koordinat editörü ve izole Phaser prototipi.
